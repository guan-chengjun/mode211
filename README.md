# 阳台光伏遮阳棚 3D 仿真

单文件、轻量化 Three.js 工程可视化。

## 运行

直接用现代浏览器打开 `index.html` 即可；Three.js 与 OrbitControls 从公共 CDN 加载。

如果浏览器限制 `file://` 下的脚本或模型请求，可在本目录启动静态服务器：

```bash
python -m http.server 8080
```

然后访问 <http://localhost:8080/>。

## 功能

- 时间滑块驱动标准太阳几何、方向光位置、光色和实时软阴影。
- 倾角滑块让 7 块光伏遮阳板同步绕 X 轴旋转。
- 实时显示太阳高度角、方位角、有效直射受光投影面积。
- 将每块遮阳板投影到阳台地面，通过凸包和栅格并集计算实际阴影面积、覆盖率与外包尺寸。
- 左键旋转、滚轮缩放、右键平移；重置按钮同时恢复视角、时间和倾角。
- 绿植尝试加载 CC0 在线低模；CDN 或模型加载失败时自动回退到程序化基础几何体。
